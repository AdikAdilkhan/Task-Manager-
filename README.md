# Тапсырмалар журналы (Task Manager Pro)

Python тілінде жазылған қарапайым әрі ыңғайлы консольдік қосымша. Бұл бағдарлама мәтіндік файл (`numbers.txt`) арқылы тапсырмаларды сақтауға, көруге, іздеуге және жоюға (CRUD операциялары) толық мүмкіндік береді.

## 🚀 Негізгі мүмкіндіктері:
- **Барлық тапсырмаларды көру:** Файлдағы барлық жазбаларды реттелген нөмірмен экранға шығару.
- **Жаңа тапсырма қосу:** Журналға жаңа тапсырманы лезде енгізіп сақтау.
- **Тапсырманы іздеу:** Мәтін немесе сөз арқылы қажетті тапсырманы тез табу.
- **Тапсырманы жою:** Тізімнен қажетсіз немесе орындалған тапсырманы нөмірі арқылы өшіру.
- **Қателерді өңдеу:** `try-except` арқылы файл табылмаса немесе қате мән енгізілсе, бағдарламаның тоқтап қалмауын қамтамасыз ету.

## 📁 Жоба құрылымы:
- `main.py` — негізгі бағдарлама коды.
- `numbers.txt` — тапсырмалар сақталатын мәтіндік файл.

## 💻 Қалай іске қосу керек?
1. Компьютеріңізде **Python 3** орнатылғанына көз жеткізіңіз.
2. Осы репозиторийдің файлдарын бір папкаға жүктеп алыңыз.
3. Терминалды (немесе VS Code / PyCharm бағдарламасын) ашып, жоба папкасына кіріңіз.
4. Бағдарламаны іске қосу үшін мына команданы жазыңыз:
   ```bash
   python main.py
